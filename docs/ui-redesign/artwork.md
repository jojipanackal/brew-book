# BrewBook drink artwork

Generated with the built-in OpenAI image generator. MidJourney was not connected. Five coordinated ink-and-watercolor illustrations accompany the saved drink without adding another control or information layer.

The original transparent 1536 × 1024 PNGs were resized to 600 × 400 WebP with Sharp: quality 78, alpha quality 90, effort 6. No image-generation dependency runs in the app. Only the current artwork is requested; black coffee/tea reuse their respective family. No drink, WFH, and leave use the neutral pause illustration.

The UI renders these as decorative images with empty alt text and fixed dimensions, skips the image if it fails to load, and respects reduced motion.
